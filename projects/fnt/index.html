FieldNeuroToolbox (FNT)

FieldNeuroToolbox (FNT) is free, open-source software for working with field neuroethology data. It brings tools for audio, video, animal tracking, RFID, ultra-wideband positioning, fiber photometry and imaging together in one desktop app. FNT runs on an ordinary laptop (Windows, macOS or Linux, with no Python installation needed), so the work can travel with the research, including to field sites far from any lab.

By Caleb C. Vogt · Donaldson Lab, University of Colorado Boulder

Fiber photometry

Video

Tools for the everyday work on behavioral video: preprocessing and re-encoding, trimming and cropping, joining recordings, and combining synchronized cameras into one grid video for scoring. For tracking there is a fast classical tracker and the Mask Tracker, which uses the Segment Anything Model to annotate animals, trains an instance-segmentation model and tracks with it; an ROI tool turns those tracks, or SLEAP's, into time spent in each region. The Behavior Scoring Studio handles manual annotation with an ethogram, a timeline and video playback.

Video: the Mask Tracker

The Mask Tracker outlines every animal in a frame, pixel by pixel, and learns to do it on its own: you label frames with the help of the Segment Anything Model, it trains an instance-segmentation network on them, and the network then finds the animals in new frames and video. It follows the same label, train and review loop as MAD.

  1. Label. Click an animal and the Segment Anything Model outlines it; a click near the outline adds a missed tail or foot, a right-click removes a spot, and a brush and eraser fix the rest. Animals that touch stay separate masks.
  2. Train. The labeled frames, and frames marked as holding no animal, train an instance-segmentation network (YOLO11-seg). A training window shows, after every epoch, the network's masks over yours on held-out frames, with their overlap score.
  3. Predict. The network outlines the animals in new frames and tracks them through videos.
  4. Review. Accept, reject or reshape each predicted mask; every decision becomes training data for the next round.

Audio: the Mask Audio Detector (MAD)

Many rodents call to each other at frequencies far above human hearing, and a single experiment can produce weeks of recordings. MAD finds those calls with a deep-learning model that learns from examples you draw directly on the spectrogram.

  1. Label. Click a call on the spectrogram and the Segment Anything Model proposes its outline; a brush and eraser refine it.
  2. Train. Confirmed calls train a segmentation network (U-Net) that marks every pixel belonging to a call.
  3. Detect. The trained model runs across whole recordings (fastest on a GPU), from the app or the command line.
  4. Review. Accept or reject each detection in the app; every decision becomes new training data for the next round.

Ultra-wideband tracking

Ultra-wideband tags give a continuous position for every animal. FNT's UWB preprocessing tool cleans and exports those tracks and measures how close animals come to one another.

Get FNT

  • Desktop app. Download the latest release for Windows, macOS or Linux from GitHub Releases, unzip it and run fnt. Video tools also need ffmpeg.
  • From source. Install the Python package to modify the code or script the tools; see the installation guide.
  • Documentation. How each tool works, step by step, at calebvogt.github.io/fnt.
  • Questions and requests. Please open an issue for bugs or features.
